## Change Log 1.0.7 — Maintenance Preview 1 (prerelease)

---11/12/2026

* Maintenance prerelease: [v1.0.7-maintenance.1](https://github.com/shardsofaperture/DVMetaDataBurnIn/releases/tag/v1.0.7-maintenance.1), built from `maintenance/1.0.7` for Intel macOS. Stable main retains 1.0.6 application code; 1.0.7 stays on the maintenance branch for owner testing. Only the shared videos, documentation, licensing and roadmap are approved for stable main.

* Corrected final ASS event duration using source-frame-aligned media duration, with a last-numbered-frame fallback when duration is unavailable.
* Preserved exact NTSC timing in frame-to-time conversion; fixed ASS minute/hour carry and rejected duplicate/backwards timeline rows.
* Isolated GUI scripts, libraries, logs, temporary files and intermediates in owned per-run workspaces, including configured scratch folders.
* Deferred scratch cleanup until the entire job exits; added ownership/path guards and cancellation of the tracked child before cleanup.
* Removed the GUI's redundant second stitch pass and its searches through prior runs. The CLI remains responsible for stitching current-run parts.
* Removed both disabled legacy heredocs and consolidated duplicated active encoding helpers while retaining the previously active defaults.
* Corrected swallowed failure status, rolling-time sendcmd escaping, quoted filter paths, JSON path escaping, missing stitch destinations and Zsh stitch-list reading.
* Repaired existing smoke tests and added synthetic timing, workspace, cancellation and media regression tests.
* Added VS Code tasks and native Xcode development documentation. No new application runtime dependencies.
* Native Xcode 15.4 build verified before the version bump; version 1.0.7 Debug/Release builds and six Swift workspace checks passed. The VS Code build task selects the owner's external Xcode locally. These are historical November 12 build/check results. The November 13 train supplement adds bounded real-camera CLI measurements; GUI, broader real-camera scenarios, independent camera-clock accuracy, player/motion/audio and Apple Silicon acceptance remain outstanding. The maintenance download is an ad-hoc signed, non-notarized prerelease; the stable release is unchanged. See `docs/releases/1.0.7-maintenance.1.md` for release notes and package verification.
