# Verified project status

Audited November 13, 2026. This is the current summary; dated reports below preserve historical evidence.

## Application and branch policy

- **Stable application: 1.0.6.** `main` at `da0a3b97126578d45d24e65573e85367c1f7979e` retains the pre-maintenance runtime. Its public package is still named [1.0.6 beta](https://github.com/shardsofaperture/DVMetaDataBurnIn/releases/tag/1.0.6beta); “stable” describes the owner's retained baseline, not completed compatibility certification.
- **Maintenance preview: 1.0.7.** `maintenance/1.0.7` at `ad21e2bbedfc00a2c97f7d1771f12fe8c046811b` retains the runtime from preview commit `5f7e13e0b9f94b98bfef32c5d828aae614265583`. [Preview 1](https://github.com/shardsofaperture/DVMetaDataBurnIn/releases/tag/v1.0.7-maintenance.1) remains a prerelease. Documentation commits after these audit baselines do not promote application code.
- PR #191 prematurely integrated maintenance code; [PR #193](https://github.com/shardsofaperture/DVMetaDataBurnIn/pull/193) restored stable runtime on main. That historical integration is **superseded**, not ongoing authorization. Main and maintenance share public documentation/licensing corrections. Only owner testing and explicit acceptance can authorize future runtime integration.
- All eight published app ZIPs contain x86_64 FFmpeg and DVRescue executables. The stable 1.0.6 app executable (and older apps) has x86_64/arm64 slices; preview 1.0.7 is x86_64-only. An arm64 UI slice does not make the Intel tools native or prove Apple Silicon operation. Current packages declare macOS **12.0 minimum**. Native build/tool evidence is Intel macOS 14 with Xcode 15.4; this is not testing across all macOS 12+ versions. Native Apple Silicon and Rosetta operation remain unverified. No Windows/Linux application support is claimed. Preview signing is ad-hoc, not notarized.
