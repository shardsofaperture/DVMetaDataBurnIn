# v1.0.7 Maintenance Preview 1

This is a prerelease from [`maintenance/1.0.7`](https://github.com/shardsofaperture/DVMetaDataBurnIn/tree/maintenance/1.0.7). This records the original preview release. The owner clarified that only documentation/licensing updates belong on stable main until maintenance testing is complete. The premature maintenance merge was reversed on main by PR #193; this branch and published package remain unconfirmed previews.

See [current project status](../PROJECT_STATUS.md) for the shared source of truth and [community validation](../COMMUNITY_VALIDATION.md) to report successful tests or discrepancies.

## Changes

- Keep the final ASS subtitle visible through the source clip's final frame.
- Preserve exact NTSC timing, recording-date discontinuities and midnight rollover; prevent invalid subtitle intervals.
- Give each run its own scripts, logs, temporary files and intermediate outputs, including custom scratch folders.
- Clean scratch storage after the entire job; stop the tracked child process before cancellation cleanup.
- Stitch current-run parts once and avoid scanning or reusing previous runs' outputs.
- Report encoder/metadata/concat failures correctly, including missing-metadata fallbacks.
- Handle quoted and Unicode paths, rolling-time sendcmd escaping and JSON manifests correctly.
- Remove verified inactive legacy code while retaining the existing UI, CLI and encoding defaults.
- Add VS Code tasks while retaining the native Xcode project and shared scheme.

## Download

`DVMetaDataBurnIn-1.0.7-maintenance.1-macos-intel.zip` contains the app, bundled FFmpeg/DVRescue, the existing license texts and embedded application build provenance. Extract the ZIP and move the app to your preferred location.

This build is for **Intel macOS (x86_64), macOS 12 or later**. Native Apple Silicon operation is unverified. The app is **ad-hoc signed and not notarized**; macOS may require manual approval before opening it. Existing FFmpeg/DVRescue binaries are preserved. Their exact dependency source/notice delivery and font redistribution evidence remain [partially verified](../THIRD_PARTY_DISTRIBUTION_AUDIT.md); the app build manifest does not establish dependency build provenance.

`BUILD-MANIFEST.json` records the exact source commit, build and package identity. `SHA256SUMS.txt` verifies the ZIP and manifest. The release is marked as a prerelease; the existing stable release remains unchanged.
