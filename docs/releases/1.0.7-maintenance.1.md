# v1.0.7 Maintenance Preview 1

This is a prerelease from [`maintenance/1.0.7`](https://github.com/shardsofaperture/DVMetaDataBurnIn/tree/maintenance/1.0.7). Additional bug fixes and testing are continuing before the maintenance work is merged into `main`.

## Changes

- Keep the final ASS subtitle visible through the source clip's final frame.
- Preserve exact NTSC timing, recording-date discontinuities and midnight rollover; prevent invalid subtitle intervals.
- Give each run its own scripts, logs, temporary files and intermediate outputs, including custom scratch folders.
- Clean scratch storage after the entire job; stop the tracked child process before cancellation cleanup.
- Stitch current-run parts once and avoid scanning or reusing previous runs' outputs.
- Report encoder/metadata/concat failures correctly, including missing-metadata fallbacks.
- Handle quoted and Unicode paths, rolling-time sendcmd escaping and JSON manifests correctly.
- Remove verified inactive legacy code while retaining the existing UI, CLI and encoding defaults.
- Add VS Code tasks while retaining the native Xcode project and shared scheme.

## Download

`DVMetaDataBurnIn-1.0.7-maintenance.1-macos-intel.zip` contains the app, bundled FFmpeg/DVRescue, complete license texts and embedded build provenance. Extract the ZIP and move the app to your preferred location.

This build is for **Intel macOS (x86_64), macOS 12 or later**. Native Apple Silicon operation is unverified. The app is **ad-hoc signed and not notarized**; macOS may require manual approval before opening it. Existing FFmpeg/DVRescue binaries are preserved.

`BUILD-MANIFEST.json` records the exact source commit, build and package identity. `SHA256SUMS.txt` verifies the ZIP and manifest. The release is marked as a prerelease; the existing stable release remains unchanged.

## Validation

- 26 synthetic regression tests and all three Zsh smoke checks.
- Six executable Swift workspace checks.
- Native Xcode 15.4 Debug and Release builds.
- Built-resource/source comparisons and packaged-app CLI self-test.
- ZIP integrity, extracted signature and executable permissions, and published-asset hash readback.

These checks do not establish GUI, real-camera-footage, playback, field-order/motion or native Apple Silicon acceptance. See the [maintenance report](../MAINTENANCE_1.0.7.md) for remaining issues and test boundaries.
